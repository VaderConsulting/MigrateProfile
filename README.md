# MigrateProfile

Empired Limited VB6 Migrate Profile tool (`MigrateProfile.exe`) that loads/saves user settings (drives, printers, home page, Documentum last-connected user), can rename the profile directory, change domain context, and log off via reboot helpers. Open `MigrateProfile.vbp` in the VB6 IDE.
